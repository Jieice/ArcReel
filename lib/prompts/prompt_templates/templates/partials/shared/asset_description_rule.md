## 资产外观描述

本体资产的 `description` 写成自足、稳定、可直接绘制的外观短段落。角色按适用情况写清外观年龄、体态、脸型与关键五官、肤色或体表、毛发与发型、上身至下身的服饰鞋履及必要配饰；动物与非人类按自身结构描述到足部或身体末端。场景写空间结构与陈设，道具写形制、材质与可识别细节。

人类本体的脸部至少写出脸型，以及能区分人物的眉眼、鼻口等关键形态组合，例如眉形、眼型、鼻梁或鼻头、口唇形态。「端正」「普通」「清俊」「姿容中等」等评价不能代替这些可绘制细节。原文没有细写五官时，仍依据时代、外观年龄和体态作少量相容的保守制作设计，把具体脸型和五官写出，并在 `reason` 或候选说明中标清制作补全；不能因原文未写五官而退回空泛评价。

先遵循用户明确的外观要求和已确认的视觉参考，再保留原文已知的稳定特征；制作补全优先级最低。缺失细节只作与时代、身份相容的少量保守制作补全，在 `reason` 或候选说明中区分原文依据与制作补全，外观段落本身只保留可见特征。商品按原图保真，品牌文字、配色、材质、比例和结构不作制作补全。

比较关系要先展开成具体外观：需要体现「像某人」「比某人高」时，先读取被比较对象已知的外观，再把所需的脸型、五官、体态等具体特征写入本条；已有信息不足时不凭空声称相似。`description` 不能依赖其他条目、「同上」或人物背景才能理解；不能假定图像模型认识项目内人物名，未注入参考图时仍须给出自足的外观。

本体描述只保留有依据的具体可见特征，内心、性格评价、隐藏情绪和经历不替代外貌；「怯懦拘谨」「青春有活力」等性格或气质评价可省略，不附在本体外观段落中。基础资产采用自然中性姿态，临时跪拜、哭喊、战斗、低头看脚等动作留给分镜；长期残疾、固定身体特征和用户明确造型保留。肤色服从原文与造型，伤病或受伤衍生可呈失血苍白，不统一写成红润。

资产图的布局、画风、光照和画质词由现有模版层提供，`description` 不填写三视图、景别或镜头指令。角色衍生的 `description` 只写相对本体的外观变化，不重复整段本体描述；`merge` 与 `skip` 的 `description` 留空，已登记资产不因本次规划自动重写。
